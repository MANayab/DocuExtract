# Roadmap

- 1.0.0: text-PDF extraction, review, validation and export.
- 1.1.0 (current): batch dashboard, combined exports, multiple invoices per PDF, labels above values, per-line GST columns, optional local OCR, search and AI discoverability.
- Next: locale-aware dates and numbers, more OCR languages, vendor templates stored only with explicit consent.
- Ideas: dedicated pages per use case for search, installable offline PWA.

Real progress is tracked in GitHub Issues. Anonymised failing invoices are the most valuable input.
