# Roadmap

## Released / implemented

- 1.0.0: text-PDF extraction, review, validation and export.
- 1.1.0: batch dashboard, combined exports, multiple invoices per PDF, labels above values, per-line GST columns, local OCR foundation and SEO.
- 1.2.0: locale-aware date and number parsing.
- 1.3.1: production version-source correction.
- 1.4.0 (in progress): selectable English (eng), German (deu) and Hindi (hin) OCR, separate from invoice locale; mixed text/scanned-page OCR, cancellation, cleanup and recovery hardening are still in progress.

## Next

- v1.5.0: vendor templates, stored only with explicit user consent.
- v1.6.0: offline PWA with a service worker; a web manifest alone does not provide offline support.

Real progress is tracked in GitHub Issues. Anonymised synthetic fixtures are preferred for OCR regression tests.
